# 🧮 스마트 올인원 계산기 (Smart All-in-One Calculator)

일반/공학용 계산기, 실시간 환율 조회 및 계산, 8종 다기능 단위 변환기를 제공하는 올인원 계산기입니다.

## 🌐 웹에서 바로 실행하기 (GitHub Pages)
👉 **[https://suguri123.github.io/calculator/](https://suguri123.github.io/calculator/)**

## 💻 Windows 실행 프로그램 (.exe)
- **[Calculator.exe 다운로드](https://suguri123.github.io/calculator/Calculator.exe)** (별도 설치 없이 더블클릭으로 즉시 실행)

## ✨ 주요 기능
1. **일반 / 공학용 계산기**: 사칙연산, 괄호, 백분율, 삼각함수(`sin`, `cos`, `tan`), 로그, 거듭제곱, 팩토리얼, 계산 기록(History) 저장
2. **실시간 환율 계산기**: 최신 환율 API 연동, 주요 16개국 통화 양방향 변환 및 전체 환율표 제공
3. **단위 변환기**: 길이, 무게, 넓이(평수), 부피, 온도, 데이터 용량, 속도, 시간 (총 8개 카테고리 전체 단위 동시 비교)
